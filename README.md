# 🌿 Маленькая Ферма

Офлайн симулятор фермы. Полностью на HTML + CSS + JavaScript, без сборки и зависимостей.

## Как запустить

**Вариант 1 — просто открыть**
Откройте `index.html` в любом браузере (двойной клик). Всё работает, включая сохранение.

**Вариант 2 — на телефоне в той же Wi‑Fi**
```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```
Затем откройте на телефоне `http://<IP-компьютера>:8080`.
При первом запуске Windows может спросить разрешение брандмауэра — разрешите для частной сети.

## Что есть в игре

- 🌾 **Поле** на 16 участков (6 открыты сразу), 5 видов культур с разным временем роста и ценой
- 💧 Полив, погода (дождь и облачность ускоряют рост), сбор урожая с шансом бонуса
- 🐔 Курицы, коровы и овцы: кормление → продукция → продажа
- 🛒 Магазин семян, животных и восстановления энергии
- 🏚️ Амбар с продажей урожая и продуктов
- ⚡ Энергия, ограничения действий, «Следующий день»
- 🏆 8 достижений и статистика
- 💾 Автосохранение в `localStorage`
- 🔊 Звуки на Web Audio API (без аудиофайлов)
- ⚙️ Настройки звука и анимаций

## Структура

| Файл | Что делает |
|---|---|
| `index.html` | Разметка экранов и интерфейса |
| `style.css` | Стили, мобильный адаптив |
| `data.js` | Баланс игры: культуры, животные, цены, достижения |
| `game.js` | Логика, состояние, сохранение, отрисовка |
| `serve.ps1` | Локальный сервер для запуска на телефоне |
| `manifest.webmanifest` | PWA-манифест (установка как приложения) |
| `sw.js` | Service Worker — кэширование для офлайн-режима |
| `icon-192.png`, `icon-512.png` | Иконки приложения |
| `make-icons.ps1` | Генератор иконок (System.Drawing) |

## Как поменять баланс

Откройте `data.js`:
- `CROPS` — цена семян, цена продажи, дни роста;
- `ANIMALS` — цена, стоимость корма, цена продукции;
- `WEATHER` — вероятности погоды (`weight`);
- `ACHIEVEMENTS` — достижения.

Логика достижений и условий находится в `checkAchievements()` в `game.js`.

## Как перенести в мобильное приложение

Сейчас это веб-игра. Варианты упаковки в APK:

1. **PWA — уже реализовано.** В проекте есть `manifest.webmanifest`, `sw.js` и иконки. После размещения на HTTPS-хостинге (например, GitHub Pages) браузер предложит «Установить приложение». На `localhost` PWA работает сразу (включая офлайн-кэш), но на телефоне по адресу вида `http://192.168...` Service Worker не запустится — браузеры требуют HTTPS.
2. **Capacitor** — превращает этот же код в нативное Android-приложение. Нужны Node.js, Android Studio / JDK.
3. **Android WebView** — минимальное приложение-оболочка, загружающее эти файлы.
4. **.NET MAUI Blazor** — если хочется C# (на этом ПК уже есть .NET SDK 9).

Логику игры можно переиспользовать в любом из этих вариантов почти без изменений.
