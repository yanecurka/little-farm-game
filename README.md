# 🌿 Маленькая Ферма

Офлайн симулятор фермы на HTML + CSS + JavaScript. Без сборки, фреймворков и зависимостей.

**Игра онлайн (PWA):** https://yanecurka.github.io/little-farm-game/
**Репозиторий:** https://github.com/yanecurka/little-farm-game

---

## Как запустить

**Вариант 1 — онлайн**
Откройте https://yanecurka.github.io/little-farm-game/ . В Chrome появится кнопка «Установить» — игра поставится на телефон как приложение.

**Вариант 2 — локально**
Откройте `index.html` в браузере (двойной клик). Всё работает, включая сохранение.

**Вариант 3 — на телефоне в той же Wi‑Fi**
```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```
Затем `http://<IP-компьютера>:8080`. На `http://...` Service Worker не запускается (нужен HTTPS), но сама игра работает.

## Что есть в игре (v2)

- ⏱️ **Таймеры в реальном времени.** Растения зреют по времени, указанному на плитке (таймер). Прогресс продолжается, даже когда игра закрыта.
- ⚡ **Рост за энергию.** Панель растения: полив за 2⚡ (−20% времени), мгновенное созревание за N⚡, удобрение (−40% времени и +1 урожай), уборка с возвратом семени.
- 🔋 **Регенерация энергии** +1 каждые 20 секунд; «Отдых» восстанавливает её полностью и меняет погоду и цены.
- 🐔 **Животные с таймерами.** Покормил → через 40–100 секунд продукция → собрать → продать.
- 📈 **Плавающие цены.** Курс меняется каждый день (×0.85 … ×1.34) — можно продавать выгоднее.
- 📋 **Задания дня** с наградами монетами и опытом (3 случайных задания из 6 типов).
- ⭐ **Уровни и опыт.** За действия даётся XP; каждый уровень +10 к запасу энергии и бонус монетами.
- 🏆 **10 достижений**, статистика, 16 участков с расширением, 5 культур, 3 животных.
- 💾 Автосохранение в `localStorage` с миграцией старых сохранений v1.
- 🔊 Звуки Web Audio API, настройки звука и анимаций, PWA + офлайн-кэш.

## Откуда идеи (исследование механик)

Перед реализацией были изучены механики похожих игр — **код не использовался**, заимствованы только идеи:

- **FarmVille** (Zynga, 2009): созревание культур в реальном времени; ускорение роста за игровую валюту («instant grow»); XP и уровни, открывающие новые культуры; животные, дающие продукцию через заданный интервал; задания и награды; увядание культур. Мы оставили таймеры, ускорение, уровни, животных и задания, но не стали добавлять увядание, чтобы игра оставалась дружелюбной.
- **Stardew Valley** (ConcernedApe, 2016): шкала энергии, которая тратится на действия и восстанавливается после отдыха/еды; полив как ежедневное действие; сезонность. Мы использовали идею energy economy и полива как ускорителя, но заменили «игровые дни» реальным временем.

Все формулы, структура состояния, UI и код написаны с нуля в этом проекте.

## Структура

| Файл | Что делает |
|---|---|
| `index.html` | Разметка экранов и интерфейса |
| `style.css` | Стили, адаптив, timer-индикаторы |
| `data.js` | Баланс: культуры, животные, задания, достижения |
| `game.js` | Логика v2: таймеры, энергия, уровни, задания, сохранение |
| `sw.js` | Service Worker — кэширование и офлайн-режим |
| `manifest.webmanifest` | PWA-манифест |
| `icon-192.png`, `icon-512.png` | Иконки приложения |
| `robots.txt` | Для корректной SEO-проверки |
| `serve.ps1` | Локальный сервер для телефона |
| `make-icons.ps1` | Генератор иконок (System.Drawing) |
| `deploy-github.ps1` | Деплой через GitHub API |

## Как поменять баланс

Откройте `data.js`:
- `CROPS` — `growSeconds` (время роста в секундах), `seedPrice`, `sellPrice`;
- `ANIMALS` — `produceSeconds`, цена и корм;
- `WEATHER` — `speed` (множитель скорости) и `weight` (вероятность);
- `TASK_TEMPLATES` — цели заданий и награды;
- `ACHIEVEMENTS` — условия проверки находятся в `checkAchievements()` в `game.js`.

## Деплой

Репозиторий уже задеплоен на GitHub Pages через `deploy-github.ps1` (GitHub Contents API + Pages API). Для повторной выгрузки после изменений:

```powershell
powershell -ExecutionPolicy Bypass -File .\deploy-github.ps1 -Token <ВАШ_ТОКЕН>
```

Токен — classic PAT с правом `repo`. После деплоя токен можно отозвать.

Альтернативные варианты упаковки в APK: Capacitor, Android WebView, .NET MAUI Blazor — игровую логику можно переиспользовать почти без изменений.
